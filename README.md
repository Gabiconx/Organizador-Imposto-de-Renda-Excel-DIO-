# 📊 Organizador e Agregador para Imposto de Renda em Excel

Desafio prático desenvolvido durante o **Bootcamp Santander**.

## 📌 Sobre o Projeto
Ferramenta construída no Microsoft Excel para organizar e reunir informações essenciais para a declaração de Imposto de Renda, contando com validações automáticas e menus de navegação.

## 🛠️ Funcionalidades
- **Controle de Entradas:** Registro eficiente e validado dos dados financeiros.
- **Navegação e Interface:** Menus intuitivos e links rápidos para uma experiência prática.
- **Validação Automática:** Recursos para garantir a consistência das informações organizadas.
